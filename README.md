# Apify

Plug Apify's actor catalogue into every Cinatra agent. Once connected, any agent that needs to scrape, crawl, or extract data can reach for an Apify actor as a tool — no per-agent wiring required.

## Capabilities

- Make Apify's actor catalogue available as tools across the workspace
- Let agents run scrapers, crawlers, and data extractors on demand
- Use Apify automation tasks from inside an agent flow
- Disconnect cleanly when you no longer want Apify tools exposed
